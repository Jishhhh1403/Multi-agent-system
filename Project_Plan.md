Section 1 — Problem Statement

Write 5–10 lines answering:

What problem does this system solve?
Who are its users?
Why can't ChatGPT alone solve this problem?
Why does it need tools?
Why does it need multiple agents?

You don't need perfect answers, but make them thoughtful.

Section 2 — Functional Requirements

Write user stories like:

A business analyst should be able to upload a CSV and ask questions.

The system should search internal documents.

The system should remember previous conversations.

Write around 20–30 requirements.

Don't think about implementation yet.

Section 3 — Non-Functional Requirements

Think like an architect.

Examples:

Response time
Scalability
Cost
Security
Reliability
Observability
Audit logs
Human approval
Streaming responses

Aim for 10–15 non-functional requirements.

Section 4 — MVP Scope

This is very important.

Everything must not be built at once.

Define the first version.

For example:

MVP can:

answer questions
search one folder
use calculator
use Python
remember conversation

MVP should not:

use SQL
browse web
create PowerPoint
send email
support multiple users

Keep the MVP intentionally small.

Section 5 — Future Features

List everything you eventually want.

Maybe 30–50 items.

Examples:

Gmail integration
Slack integration
GitHub agent
SQL agent
Browser agent
Reflection
Self-correction
Memory
Voice
Vision
Multi-agent planning
Dynamic tool loading
LangSmith
MCP
Human approval
Cost optimization

This becomes your product backlog.
